プライバシーポリシー

AIエージェント ／ 最終更新日：2026年10月12日

1. このアプリについて

AIエージェント（以下「本アプリ」）は、運営者が自分の YouTube チャンネルを運営するために使う個人用のツールです。一般向けに提供しているサービスではありません。

2. 取得する情報

本アプリは、Google アカウントでログインして許可を得たうえで、YouTube API サービスを通じて次の情報を扱います。

  • チャンネルの基本情報（チャンネル名・ID など）
  • 動画の情報（タイトル・説明文・サムネイル・公開設定など）
  • 再生回数・視聴時間などの分析データ

3. 情報の使い道

取得した情報は、運営者自身のチャンネルへの動画の投稿・設定と、チャンネルの分析にのみ使います。分析のため、運営者が使う AI ツールで情報を処理することがあります。

4. 情報の保存

ログインで得た認証情報（アクセストークン）は、運営者のパソコンの中にのみ保存します。本アプリが独自のサーバーに保存することはありません。

5. 第三者への提供

取得した情報を第三者に販売・提供することはありません。

6. アクセスの取り消し

本アプリへのアクセス許可は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。
https://myaccount.google.com/connections

7. YouTube API サービスと Google のポリシー

本アプリは YouTube API サービスを使用しています。本アプリを使うことで、次の規約・ポリシーにも同意したことになります。

  • YouTube 利用規約：https://www.youtube.com/t/terms
  • Google プライバシーポリシー：https://policies.google.com/privacy

本アプリによる Google API から受け取った情報の利用と他アプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に従います。

8. 改定

本ポリシーを改定するときは、このページを更新します。

Privacy Policy

AIエージェント / Last updated: October 12, 2026

1. About this app

AIエージェント ("the App") is a personal tool used by its operator to manage their own YouTube channel. It is not offered as a public service.

2. Information accessed

After the user signs in with a Google account and grants permission, the App accesses the following through the YouTube API Services:

  • Basic channel information (channel name, ID, etc.)
  • Video information (titles, descriptions, thumbnails, privacy settings, etc.)
  • Analytics data such as views and watch time

3. How information is used

The information is used only to upload and configure videos on, and analyze, the operator's own channel. It may be processed by AI tools the operator uses for that analysis.

4. Storage

Authorization credentials (access tokens) are stored only on the operator's own computer. The App does not store them on any server of its own.

5. Sharing

The App does not sell or share the information with third parties.

6. Revoking access

You can revoke the App's access at any time from your Google Account's third-party connections page:
https://myaccount.google.com/connections

7. YouTube API Services and Google policies

The App uses YouTube API Services. By using the App, you agree to be bound by the YouTube Terms of Service and the Google Privacy Policy.

The App's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

8. Changes

Any changes to this policy will be posted on this page.

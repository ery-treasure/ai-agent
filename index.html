AIエージェント

YouTube チャンネル運営のための個人用ツール

このアプリについて

AIエージェント は、運営者が自分の YouTube チャンネルを運営するために使う個人用のツールです。YouTube Data API と YouTube Analytics API を使い、次のことを行います。

  • 運営者自身のチャンネルへの動画の投稿
  • 動画のタイトル・説明文・サムネイルの設定
  • 運営者自身のチャンネルの再生回数などの分析データの取得

一般向けに提供しているサービスではありません。

About

AIエージェント is a personal tool used by its operator to manage their own YouTube channel. It uses the YouTube Data API and YouTube Analytics API to upload videos, set titles, descriptions and thumbnails, and read analytics for the operator's own channel. It is not offered as a public service.
